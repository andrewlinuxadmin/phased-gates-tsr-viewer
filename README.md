# OpenShift TSR Viewer

A self-contained HTML viewer for **Phased Gates** JSON reports generated from OpenShift must-gather analysis.

**Live demo:** https://andrewlinuxadmin.github.io/phased-gates-tsr-viewer/

## Overview

`tsr-viewer.html` is a single-file HTML application (no external dependencies) that lets you load, browse, filter, annotate, and export Phased Gates analysis results from OpenShift clusters. It works entirely offline in the browser.

> **Privacy:** All data is processed locally in your browser. No information is sent to any external server — your JSON files never leave your machine.

## Usage

1. Open `index.html` (or `tsr-viewer.html`) in any modern browser.
2. Click the **Load JSON** button (folder icon) to load a `.pg.json` file generated by Phased Gates.
3. Browse checks using the main table and sidebar filters.

## Features

### Visualization
- Interactive table with all report checks
- Detail panel showing full results, links, tips, and remediations
- Configurable and resizable columns (number, name, status, tags, etc.)
- Responsive layout with resizable sidebar and detail panel
- Dark theme (Red Hat branded)

### Filters (Sidebar)
- **Session** — filter by session (when multi-session)
- **Check status** — `pass`, `fail`, `warning`, `info`, `NA`, `skip`, `skip_with_content`
- **Inner result status** — inner statuses like `limitation`, `support limitation`, etc.
- **Topic** — report topics/sections (e.g., "ETCD", "Topology")
- **Subsection** — hierarchical subsections
- **Tags** — check tags
- **More** — advanced filters:
  - Check number (e.g. "4.8")
  - error_key, component, skip reason
  - Filter by links (with/without)
  - Only checks with inner FAIL
  - Hide SKIP and N/A
  - Show marked only
  - Show only checks with notes

### Search
- Global search in the toolbar (searches name, number, messages, tags)
- Detail panel search with result navigation
- Supports operators: quotes for exact phrase, `-` to exclude

### Marking & Notes
- Mark/unmark individual checks (table checkbox)
- Add per-check notes (persistent text field)
- Notes expand into a modal for detailed editing
- Data persists in browser `localStorage`

### Export
- **JSON (marked)** — export marked checks as JSON
- **HTML (marked)** — export marked checks as an HTML report
- **JSON (all)** — export all filtered checks as JSON
- **HTML (all)** — export all filtered checks as an HTML report

### Comparison
- Load a second JSON to compare against the current one
- Identifies checks that **worsened**, **improved**, were **added**, or **removed**
- Visual indicators in the table (colored left border)
- Filter by change type
- Export diff (JSON and HTML)

### Keyboard Shortcuts
- Press `?` to see all available shortcuts
- Arrow key navigation in the table
- Quick filter shortcuts

### Session Persistence
- UI state (filters, layout, notes, marks) auto-persists via `localStorage`
- "Forget session" button clears all saved data
- URL hash updates to the selected check (shareable direct links)

## Input Format

The viewer accepts `.pg.json` files generated by Phased Gates. Expected structure:

```json
{
  "analysis_metadata": { ... },
  "rule_sets": {
    "ccx_rules_ocp": { ... },
    "phased_gates": {
      "must_gather": { ... },
      "skips": { ... }
    }
  },
  "system": {
    "metadata": {
      "cluster_id": "...",
      "cluster_name": "...",
      "cluster_version": "..."
    }
  }
}
```

The file contains hierarchical checks organized in numbered sections (1.x through 7.x), where each check has `node_metadata`, `content`, `result`, and `tags`.

## Requirements

- Modern browser (Chrome, Firefox, Edge, Safari)
- No external dependencies or server required
- Works completely offline

## JavaScript API (Advanced)

The viewer exposes `window.TSRViewer` with utility methods:

- `ingest(data)` — load data programmatically
- `applyFilters()` — apply current filters
- `getChecks()` — return all checks
- `getFiltered()` — return filtered checks
- `getMarked()` — return marked checks
- `getNotes()` — return notes
- `buildExportJson()` / `buildTsrHtml()` — generate exports
- `buildCompareJson()` / `buildCompareHtml()` — generate comparisons
